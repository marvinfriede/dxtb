# E3.1s-b — invariant free-energy spectral closure

E3.1s-b completes the dxtb-local invariant spectral path. Functional SCF
free-energy corrections now use a weighted spectral matrix rather than
derivatives through reporting eigenvectors or individually ordered orbital
energies.

For smeared Fermi filling, the matrix represents
`kT [f log(f) + (1-f) log(1-f)]` by a fixed tensor quadrature of the matrix
Fermi function. It consumes the compact `_FermiCoreState` retained by the
selected spectral evaluation: the chemical-potential reference and offset,
channel classifications, structural orbital mask, and Fermi status. It does
not run another primal Fermi search. Equal partitioning distributes the
overlap-weighted trace across real atoms; atomic partitioning uses Mulliken
populations of the same AO matrix. Thus both partitions conserve the same
total correction.

For positive temperatures below the smearing cutoff, the existing clamped
Aufbau occupation and free-energy convention remain in force, including
fractional frontier occupations. With no Fermi settings, the correction
remains exactly zero. Invalid or unconverged Fermi channels retain a zero
diagnostic matrix. The private Fermi state is fixed-shape tensor data and is
selected alongside the corresponding spectral result through the solver.

The functional reporting eigensystem now always uses the ordinary fixed
forward `storch.eighb` configuration. No functional SCF free-energy or
density derivative selects spectral semantics from `requires_grad`; reporting
coefficients and orbital energies do not own these physical derivatives.

- Functional map, solver, Fermi derivative, and filling selection: 105 passed.
- Canonical E0 spectral targets: 24 passed; no status-file changes.
- Focused E3.0 frozen NO2 spectral control (PyTorch): 1 passed.
- Focused E3.1a root/IFT selection: 7 passed.

  XFAILs. The stored references and `KNOWN_WRONG` markers are unchanged.
- Black, Python compilation, and `git diff --check` passed.

E3.1s is complete. The next package is E3.1b, which attaches the physical-root
derivative to the accepted convergence-tested raw-map input. The NO2
finite-root diagnosis and historical markers remain unchanged.
