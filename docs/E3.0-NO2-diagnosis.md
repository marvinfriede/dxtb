## Diagnosis and validation

The evidence supports this current localization:

```text
map 8 physical output: derivative-level consistency within the measured bound
Anderson transition after map 8: first large mismatch for both observables
map 9 at actual propagated tangent: tested density derivatives agree with FD
fixed-damping Simple map composition: derivative-level consistency
Anderson solve conditioning: center-specific spike at the following transition
fixed N=20 / historical tolerance: mismatch for both observables
fixed N=24 / tighter tolerance: both responses approach their FD plateaus
potential finalization: preserves/amplifies the existing mismatch
public property composition: reproduces the historical endpoint failure
```

The localized result is possibility A for the tested prefix: the Anderson
history transition after map 8 first introduces the derivative-level
inconsistency for both observables. The fixed-damping control and actual
map-9 tangent probes do not identify raw-map differentiation as the onset.
More maps and tighter convergence improve both responses. However, the
fresh-calculator experiment also finds reproducible call-order variation in
the public nested derivatives while the converged Result tensors remain
unchanged. Its mechanism is not yet localized to a specific mutable object or
operation, and must be resolved before E3.0 closes. The canonical E0 spectral
target failures remain unchanged. E3.0 selects no numerical remedy; E3.1
remains unstarted.

The current focused diagnostic tests assert the fixed-N N=18/20/22/24
characterization, the first failing prefix, tolerance-sweep convergence,
sampled intermediate-map agreement, all four solver/finalization boundary
cases, eager/fixed-trip center parity and the Case A/B route contract. The
canonical component selection above and the GFN2/NO2 reference selection are
separate required evidence. No references, tolerances, `KNOWN_WRONG` entries,
