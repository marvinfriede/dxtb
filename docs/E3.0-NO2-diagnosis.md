# E3.0 diagnosis: GFN2/NO2 third derivatives

E3.0 reproduces the existing GFN2/NO2 failures and localizes the first failing
boundary to the complete SCF solver trajectory. The raw map is consistent with
finite differences. The selected trajectory response is already inconsistent;
potential-mode finalization and the public property composition retain or
amplify that error. Eager early-stop and fixed-trip control give the same
derivatives for this case. This is diagnosis only; it changes no physics,
solver policy, references, tolerances, or `KNOWN_WRONG` entries. E3.1 has not
started.

The target is the existing open-shell `SYSTEMS["NO2"]` doublet (`spin=1`). Case

potential SCP representation and finite-temperature Fermi configuration

PyTorch and libcint.
