## Scope and policy

S11 keeps the accepted primal portfolio unchanged: Linear, Anderson, Broyden,
CDIIS, and fixed-occupation SOSCF, including the accepted multistage strategy
combinations. Active Fermi smearing continues to use first-order Broyden,
Anderson, or CDIIS. SOSCF remains fixed-occupation-only and eager-only.

The implicit response is a property of a certified physical root. It does not
depend on the primal method, its history, a switch decision, or an SOSCF inner
trajectory. The default response coordinates remain the final primal
representation. S11 adds an internal-only override for testing and
characterization; no public configuration/default is selected.

## Response-root preparation

`functional/response.py` owns the method-independent response boundary. It
retains only the physical root, its raw map and explicit tensor parameters,
certification, and a stripped primal outcome. The response object does not
retain solver traces, strategy diagnostics, or method states.
The eager orchestration preserves the original primal `SCFStrategyDiagnostics`
on the returned result separately; alternate-coordinate preparation cannot
replace its stage/switch record.

For a requested alternate coordinate system, preparation starts from the
already-certified final spectral observation and constructs:

* charge coordinates by packing the final spectral charges;
* potential coordinates from the potential generated by those charges;
* Fock coordinates from the physical Fock rebuilt from those charges.

The candidate receives exactly one raw physical map evaluation and the normal
S2 certification at the primal tolerances. There is no mixing, iteration,
refinement, or extra SCF solve. If the candidate does not independently
certify, response attachment raises `SCFConvergenceError`. The default
same-representation path keeps the existing primal root/map pair and is
revalidated at the exact implicit parameter boundary.

## Linear response controls

`SCFResponseSettings` is internal and immutable. It accepts an optional
`SCFRepresentation`, `rtol`, `atol`, and `maxiter`; defaults remain `1e-10`,
`1e-12`, and the existing dimension-based limit. The production implicit
attachment remains the pinned `tad_mctc.storch.implicit.implicit_fixed_point`
BiCGSTAB primitive. `functional/implicit.py::solve_linear` remains a
diagnostic/reference operator and is not a second IFT implementation.

The root check now uses strict `<` comparisons for both fixed-point residual
thresholds, matching S2 certification. The exact-boundary regression protects
this convention.

## Operator and coordinate evidence

The physical response operator in each coordinate system is `A = I - G_x`.
For H2/GFN1, tests compare matrix-free `A v` and `A.T v` against dense
Jacobian references in charge, potential, and the production full-matrix Fock
coordinates. H2O/GFN2 is also small enough for dense conditioning references.
The Fock benchmark does not substitute a packed symmetric half-matrix for the
implemented coordinates. Physical hcore tangents and a nonzero weighted
Mulliken-charge adjoint are used for BiCGSTAB diagnostics.

Benchmark JSON under `benchmarks/results/scf-s11/` records environment,
primal maps, coordinate dimension, candidate residual, Krylov iteration and
residual, timing, and (for H2) dense conditioning and parity. H2O/GFN2 and
NO2/GFN2 extend the matrix-free measurements. A transformed response root is
not allowed to use a looser tolerance to hide residual amplification.

## Derivative and failure contract

Tests compare Broyden and Anderson roots across all three response
representations for energy/free energy, density, charges, first field
derivatives, and a nested second field derivative. A separate H2/GFN1
geometry-coordinate comparison checks first-derivative agreement between
Broyden and CDIIS in common potential response coordinates. A genuine
differentiable GFN2 parameter (`charge.effective.gexp.param`) is exercised
through second order. The hybrid fixed-occupation strategy comparison covers
field derivatives through third order; the active-smearing NO2 strategy matrix
covers first and second field derivatives. These are the measured strategy
comparisons, not claims of a full geometry/parameter/third-order Cartesian
product across every strategy and response representation. A response linear
tolerance sweep checks H2 field derivatives through third order at `1e-8`,
`1e-10`, and `1e-12`. Physical forced-low-iteration tangent and adjoint solves return
non-finite derivatives; ordinary settings remain finite. A nested derivative
after a failed response remains visibly non-finite.

`_SCFMapTensorTree` keeps all floating physical raw-map dependencies explicit.
The field/multipole/thermal GFN2 test verifies parameter-path/flatten
consistency and raw-map round-trip parity, including expanded interaction
views at the transform boundary.

## Derivative order and support boundary

The existing independent NO2 physical finite-difference/hyperpolarizability
reference remains the third-order physical anchor; it validates the physical
response against fresh independently solved roots, not strategy spread.
Broyden/Anderson and active
smearing Broyden/Anderson/CDIIS/hybrid response comparisons cover first and
second derivatives. A fixed-occupation CDIIS versus
Broyden-to-CDIIS-to-SOSCF comparison includes a third field derivative. The
accepted NO2 hyperpolarizability reference passed at its root-tolerance sweep,
comparing against fresh physical finite-difference roots. A separate
NO2/GFN2 implicit third field derivative also agrees between potential and
full-Fock response coordinates.

The large C4H5NCS/GFN2 root certified in 48 primal maps. Its full-Fock
response uses 1444 actual coordinates and converges in 12 tangent and 12
adjoint BiCGSTAB iterations. Process peak RSS was about 1.80 GiB for all three
runs; the benchmark never constructs a dense response Jacobian.

The intended support matrix is:

| Primal execution | FULL/unrolled | IMPLICIT |
| --- | --- | --- |
| Single-stage Linear | supported by existing fixed-trip path | supported |
| Single-stage Anderson | supported by existing fixed-trip path | supported |
| Single-stage Broyden | supported by existing fixed-trip path | supported |
| Single-stage CDIIS | supported where current transform tests pass | supported |
| SOSCF | eager-only | supported after certified root |
| Dynamic multistage strategy | eager-only | supported after certified root |
| Active-smearing first-order methods | supported by existing spectral contract | supported |

This table describes the current internal architecture; it does not promise
unrolled third derivatives through solver history. No public response
representation or solver default is selected. S12 owns transform/compile
hardening, and S13 owns public API/default stabilization.
