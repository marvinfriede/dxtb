# U1–U4.3 D3 0.7 integration

## Decision

Official `tad-dftd3==0.7.0` works with the accepted upgraded core stack and
preserves the E1.3/E6a numerical and transform acceptance selection. D3 0.6
is no longer supported by current code, tests, installation instructions,
tox, CI or current dependency guidance. Historical reports retain 0.6
references where they record the environment actually used at that time.

**D3 0.7 compatibility: VERIFIED.**

**E1.3/E6a derivative contract: PRESERVED.**

**Public release readiness: BLOCKED** by the already accepted D3/D4 published
metadata conflicts and separate release gates. This work does not change
that decision.

## Implementation

The D3 adapter now always calls `d3.model.atomic_c6`; the D3 0.6 functorch
version branch and duplicated reference-table contraction were removed.
The adapter still accepts `chunk_size` for compatibility and emits its
existing deprecation warning when a value is supplied; it does not chunk or
provide an alternative C6 algorithm.

Cutoff tests now use D3 0.7's structured `d3.Cutoff` directly. They compare
the production adapter's shared 50-bohr convention to the official combined
API, show that a narrower cutoff changes energy and gradient, and compare
separate two-body/ATM cutoff contributions with the combined result. No
reference values or tolerances changed.

The mctc shim retains the guarded `is_batched` alias required by D3 0.7's
import path. D3/D4 must be imported after `dxtb`, which applies the shim.
Nested forward/reverse/vmap tests passed with this alias on every matrix
profile. The existing `ncoord.legacy` compatibility layer remains required
for the published dispersion API and is otherwise unchanged. The unused
`memory_device`, `pow`, and `reciprocal` aliases were removed after checking
the installed D3 0.7/D4 0.8 sources and dxtb consumers. This also removes the
shim's now-unneeded `psutil` dependency from runtime, docs requirements, and
the baseline constraints.

test failures or skips.

The passing D3 tests exercise official AtomicC6, coefficient/weight and
energy references, position and parameter derivatives, two- and three-body
cutoffs, `grad`, `jvp`, `jacfwd`, `jacrev`, `vmap`, nested transforms,
second/third derivatives, trainable `s6`, `s8`, `a1`, `a2`, and the mandatory

singlepoint, conformer vmap, mapped gradients, and status behavior. Existing
references and tolerances were unchanged.

The PairPlan dtype and Calculator exact-core dtype regressions were rerun
after the final shim cleanup: seven tests passed on both Python 3.11/Torch
2.8 and Python 3.14/Torch 2.14.1, including Calculator conversion and pair
setup conversion-isolation controls.
