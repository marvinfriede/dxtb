# SCF S13.1 — public-boundary consistency hardening

S13's numerical decisions remain accepted: Anderson/Potential is the default,
unrolled differentiation is the default, Potential is the implicit response
coordinate, the existing convergence profiles and iteration budget remain
unchanged, and SOSCF remains opt-in, fixed-occupation, and eager-only. This
package corrects two API consistency defects without changing the physical SCF
maps or default benchmark policy.

## Parser authority

Legacy construction inputs are parser-edge adapters. An old input can be used
when the corresponding new input is omitted; supplying both is rejected even
if their values would agree. The rules are:

| New authority | Legacy adapter | Result when both supplied |
| --- | --- | --- |
| `strategy` | `mixer` | reject |
| `strategy` / stage representation | `scp_mode` | reject |
| `differentiation` | `scf_mode` | reject |
| explicit `strategy` | Anderson damping keywords | reject |

When `differentiation` and `scf_mode` are both omitted, differentiation
resolves to `unrolled`. A legacy-only `scf_mode` is translated. Legacy-only
`mixer` plus `scp_mode` remains supported, as do legacy Anderson tuning
keywords when no explicit strategy was provided. The CLI remains new-API-only.

## Batch implicit response

Conformer-batch preparation now keeps primal and response representations,
roots, adapters, parameters, and layouts distinct. Each valid primal lane is
passed through the same `prepare_response_root()` implementation as the
single-System path. Same-coordinate preparation reuses the validated physical
observation. An alternate coordinate is constructed from that observation,
evaluated once, and independently certified; it is never iterated or silently
replaced by the primal coordinate.

The mapped IFT and its response diagnostic collector both receive the configured
`SCFResponseSettings` (`representation`, `rtol`, `atol`, and `maxiter`). Result
iterations, residual, status, and strategy diagnostics continue to describe
the primal solve. Invalid primal lanes do not receive response roots, and
response failures remain lane-local and fail closed.

Same-coordinate batches retain the original primal adapter/root/parameter path
to preserve nested-transform behavior. Alternate-coordinate response roots and
their metadata are carried separately through streaming subsets. The shared
route resolver remains FULL-only by default; conformer-batch preparation opts
into the implicit route explicitly.

The existing padded-core batch boundary supports response conversion only when
the response and primal representations match. A mismatched request is
rejected before response preparation; public mixed-System routing is outside
S13.1.
