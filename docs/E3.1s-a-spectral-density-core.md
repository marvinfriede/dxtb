# E3.1s-a — dxtb-local invariant SCF density core

E3.1s-a moves the physical density in the functional SCF map from
`C diag(occupation) Cᵀ` to private gauge-invariant matrix functions in
`dxtb._src.scf.functional.spectral`. `storch.eighb` remains the ordinary
forward source of orbital energies and coefficients. The four canonical E0
spectral component targets now exercise the dxtb density primitive.

The Aufbau path uses fixed-rank matrix projectors plus the differentiable
fractional frontier weight, preserving dxtb's channel-resolved fractional
electron convention. The finite-temperature path reuses the split detached
chemical-potential root `(reference, offset)`, channel classifications, gap
classification, and structural masks from the single authoritative dxtb Fermi
core; it does not collapse the root or run a second Fermi search.
The generalized density is formed in the orthogonalized basis and transformed
back through the differentiable inverse-Cholesky factor. The physical density
therefore feeds charges, mapped SCF state, and energy without differentiating
through arbitrary coefficient columns. The `requires_grad`-selected broadening
switch was removed from the functional physical-density path. Until E3.1s-b
migrates atomic entropy partitioning, that coefficient-based entropy path
retains its former reverse/JVP-specific broadening behavior. This compatibility
branch is confined to the unfinished entropy observable and does not affect
invariant density derivatives.

An exact zero-temperature degeneracy across differently occupied states is
outside the differentiable contract. The fixed-rank matrix-sign projector is
singular there and propagates `torch.linalg.LinAlgError`; it does not return a
manufactured finite derivative. Equal-occupation internal degeneracies remain
covered by rotation-invariance tests. The finite-temperature checks include a
nonzero-temperature derivative of a weighted density observable against a
stable physical finite-difference window, in addition to fixed-electron trace
conservation.

The supported atomic free-energy partition still forms its entropy matrix
from eigenvector columns. That is explicitly deferred to **E3.1s-b — invariant
entropy/free-energy spectral matrix closure**; E3.1s and E3.1b remain blocked
until that follow-up is complete.

intermittent higher-order mismatch seen when several isolated order-3 checks
ran concurrently; the affected isolated order-3 checks also pass individually.
Separate integrated tests assert one Fermi primal worker invocation per
spectral evaluation, reuse of its status and configured alpha/beta/mask
inputs, and channel-wise occupation conservation for GFN2/NO₂. The invariant
density suite explicitly exercises `torch.func.jacfwd` for fractional Aufbau,
finite-temperature degeneracy and small gaps, and generalized-overlap
perturbations. A two-lane vmap test uses distinct orbital masks and checks
zero density leakage from masked Hamiltonian and inverse-Cholesky entries.
